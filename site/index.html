How to read these numbers

Basic totals and averages use the selected games. Shooting percentages use total makes and attempts, not an average of game percentages. An em dash means unavailable or no attempts.

Estimated possessions = the average of each team’s (field-goal attempts − offensive rebounds + turnovers + 0.44 × free-throw attempts). Pace adjusts that estimate to 40 minutes, including overtime in game duration. Offensive and defensive ratings show points scored and allowed per 100 estimated possessions.

These estimates require confirmation that both teams’ full stats were recorded; pace also needs recorded game duration. Eligible game counts appear on the cards. eFG% accounts for the extra value of threes; TS% also includes free throws. Neither measures overall defensive impact.

Spring: March–July. Fall: August–February, labeled by the starting year. Calendar-year views run January–December. Unclassified historical games appear only with both categories selected.

Definitions: Basketball Reference glossary and Four Factors. CourtSide uses the displayed simple possession estimate and a 40-minute pace.
